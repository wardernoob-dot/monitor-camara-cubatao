# Fotos dos vereadores

Jogue aqui a foto de cada vereador, com qualquer nome que lembre quem é:
`xuxa.jpg`, `Daniel Barbosa.png`, `marcos-roberto-silva.jpeg`, `Topete.webp`...

O robô reconhece pelo apelido ou pelo nome civil, recorta quadrado puxando para o rosto,
reduz para 480 px, converte para WebP e publica no site (`docs/fotos/<vereador>.webp`).
Sem foto, o site mostra as iniciais. Se um arquivo não casar com ninguém, o log do robô avisa.

Como subir pelo GitHub: abra esta pasta, "Add file" → "Upload files", arraste os arquivos e confirme.
