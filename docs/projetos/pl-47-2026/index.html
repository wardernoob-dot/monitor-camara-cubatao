Ementa (texto oficial)

Acrescenta dispositivo à lei n° 3.763, de 28 de outubro de 2015, para assegurar a inclusão das pessoas com transtorno do espectro autista entre os beneficiários.

Em linguagem simples

Este projeto inclui as pessoas com autismo entre os beneficiários de uma lei municipal antiga. A lei antiga garante a entrega de remédios e materiais médicos na casa das pessoas. O objetivo é evitar dúvidas e garantir que os autistas recebam esses produtos em casa. A medida facilita o tratamento e dá mais segurança para as famílias.
