Em linguagem simples

O projeto dá um nome oficial para um espaço dentro da Câmara Municipal de Cubatão. O local de exposição passa a se chamar "Gabinete Histórico Presidente João Faustino Alvarenga". A medida serve para homenagear o ex-vereador e ex-presidente da Casa. O texto tem efeito simbólico para a memória da cidade.
