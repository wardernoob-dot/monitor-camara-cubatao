Ementa (texto oficial)

Dispõe sobre a alteração da lei nº 4.391, de 8 de agosto de 2025, para criar os padrões de função gratificada f18 e f19 no quadro da Câmara Municipal de Cubatão

Em linguagem simples

O projeto cria dois novos valores de gratificação para funcionários da Câmara Municipal de Cubatão. Ele muda uma lei anterior para incluir os padrões chamados F18 e F19. O objetivo é pagar salários maiores para cargos que exigem mais responsabilidade técnica. A lei vale logo após ser publicada.
