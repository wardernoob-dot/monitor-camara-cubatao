Em linguagem simples

Este projeto muda uma lei do orçamento da cidade. Ele aumenta o limite para a prefeitura remanejar dinheiro entre secretarias. O limite passa de 10% para 19% do total dos gastos. A medida vale para a prefeitura e para a Câmara Municipal.
