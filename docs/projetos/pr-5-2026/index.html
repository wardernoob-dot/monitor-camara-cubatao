Ementa (texto oficial)

Dispõe sobre o programa de capacitação institucional da Câmara Municipal de Cubatão e disciplina o ressarcimento ao erário

Em linguagem simples

O projeto cria regras para cursos pagos pela Câmara Municipal para os servidores. Ele define as obrigações de frequência e notas, e diz quando o funcionário deve devolver o dinheiro gasto caso desista ou seja reprovado. A medida busca organizar o uso do dinheiro público em treinamentos e garantir o retorno para o órgão. O texto vale para os contratos que já estão valendo e também para os futuros.
