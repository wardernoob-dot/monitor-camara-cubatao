Como funciona

Este site lê todos os dias os documentos públicos da Câmara Municipal de Cubatão e organiza o que foi votado, quem votou como e o que aconteceu com cada projeto depois. Ninguém escolhe à mão o que entra.

De onde vêm os dados

Painel de votação na transmissão
Durante cada votação a TV Câmara mostra o painel eletrônico com a foto de cada vereador: moldura verde para sim, vermelha para não, branca para quem está presente e não votou, foto apagada para quem está ausente. O sistema lê esse painel nas imagens de prévia do vídeo publicado no YouTube, sem baixar o vídeo. É a fonte dos votos individuais a partir de setembro de 2026. Cada voto tem link para o momento exato da transmissão.
Pauta da sessão
Publicada na véspera. Diz o que vai ser votado, quem é o autor e qual é o assunto. Serve também para conferir a leitura do painel: um número de projeto lido no painel só é aceito se estiver na pauta daquele dia.
Resumo oficial da sessão
Publicado pela Câmara cerca de duas semanas depois. Registra presença, resultado e os nomes de quem votou a favor e contra. É a fonte dos votos de fevereiro a agosto.
Texto dos projetos
PDFs publicados no site da Câmara. Quando o PDF é uma imagem escaneada, o texto é transcrito automaticamente.
Diário Oficial do Município
Mostra quando um projeto aprovado vira lei.

Quando as fontes não batem

O resumo oficial costuma listar como favoráveis todos os vereadores presentes numa votação sem votos contrários, inclusive quem aparece no painel sem ter votado. Em pelo menos um caso o painel mostra um voto contrário que o resumo registra como favorável. O site mostra as duas versões lado a lado, sem tirar conclusão, na página de cada projeto.

Uso de inteligência artificial

A inteligência artificial é usada em três pontos, sempre com conferência:

  • Ler o texto miúdo no topo do painel, que diz qual projeto está em votação. O número lido é conferido contra a pauta do dia.
  • Transcrever PDFs escaneados de projetos.
  • Escrever a seção “Entenda o projeto”. O modelo recebe só o texto do projeto, sem votos, nomes de vereadores ou partidos. Cada ponto de atenção precisa citar um trecho literal do projeto, e o sistema confere se esse trecho existe; se não existir, o ponto é descartado. As instruções enviadas ao modelo são públicas: leia o texto completo.

Os votos individuais nunca passam por inteligência artificial: são lidos pela cor de cada moldura no painel.

Limites

  • Votações simbólicas, sem painel, não têm registro nominal.
  • Antes de setembro de 2026 não há registro de quem estava presente e não votou.
  • Projetos em PDF escaneado podem ficar sem autoria identificada até serem transcritos.
  • O Diário Oficial é consultado para os últimos 45 dias a cada atualização.

Código

Todo o código e todos os dados coletados ficam num repositório público: github.com/wardernoob-dot/monitor-camara-cubatao. Se encontrar um erro, abra um aviso por lá.
